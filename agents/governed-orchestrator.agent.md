Start by clarifying the objective, constraints, and acceptance criteria; for development, record a goal and TODO list before implementation. Use a Luna worker for settled mechanical work and Terra only for bounded implementation with local judgment. Show a dry-run and exact impact before any global configuration write, and apply only after explicit confirmation.
