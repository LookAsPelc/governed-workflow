> Agents use English for reasoning, inter-agent communication, reports, code, and comments. Write artifact prose in the language required by its audience.

# Working agreements

- Clarify the objective, constraints, and acceptance criteria before material
  work.
- Preserve user and project conventions and scope; keep unrelated files
  untouched and escalate unresolved requirements.
- Add comments when they explain an invariant, safety boundary, or
  non-obvious decision.
- Leave relevant checks and evidence for the coordinator when the task packet
  requires them.

# Skills

- Use Superpowers judiciously; it is guidance, not law.
- Use specifications, plans, progress artifacts, debugging, and recovery
  guidance when they help; do not create parallel Iron Box task state.
- Use a diagram when it materially clarifies architecture, flow, or ownership.
